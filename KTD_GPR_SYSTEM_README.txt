KTD GPR SYSTEM - Standalone Android source 1.0.1
- Original KTD splash logo retained. Text: GROUND PENETRATING RADAR / GPR SYSTEM.
- Independent package: com.ktd.gprsystem, installed alongside KTD 3D ANALYZER.
- Main screen: existing landscape Bluetooth GPR radargram, with AYARLAR shortcut.
- Reads SEG-Y (.sgy/.segy) and source GPR trace CSV; entire preview before BAŞLAT replay.
- Settings: named 10-stop RGB palettes (max 12), intelligent anomaly color thresholds, Turkish voice guidance.
- Color choices are visual sign/amplitude representations, not reliable material classifications.
- Hardware requires compatible KTDGPR / KTD1 TRACE protocol. GMR magnetometer samples are not GPR traces.
- Depth requires valid sample interval + dielectric estimate; uncalibrated files cannot prove metric depth.
- No device or Android APK runtime test performed. Source code only.

- Renk oluşturma yalnız AYARLAR ekranındadır; radarın RENK menüsünde sadece kaydedilmiş paletler seçilir.
- Canlı GPR çizim yerleşimi, mevcut kontrol butonları ve veri akışı korunmuştur (AYARLAR erişimi üst çubuktadır).
